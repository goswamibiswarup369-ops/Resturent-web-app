# 🌶️ Spice Haven – Responsive Restaurant Website

Spice Haven is a colorful, fully responsive restaurant website built with HTML, CSS, and JavaScript.  
It showcases a modern multi‑page layout for an Indian restaurant opened in 2026 in Dhatrigram, West Bengal.[web:3][web:50]

---

## 🔍 Project Overview

Spice Haven is a complete business website for a restaurant, designed as a beginner‑friendly full web development project.[web:1][web:51]  
It includes multiple pages (Home, About, Menu/Services, Contact), a responsive layout, interactive navigation, and a contact form with validation.[web:3][web:54]

---

## 📁 Project Structure

- `index.html` – Home page with hero section and signature menu.  
- `about.html` – Restaurant story, mission, values, team, and opening year (2026).  
- `services.html` – (Optional) Detailed menu or services page.  
- `contact.html` – Contact and reservation form.  
- `css/style.css` – Main styles, responsive design, dropdown menu, animations.  
- `js/script.js` – Mobile navigation toggle, dropdown behavior, form validation.  
- `images/` – Optimized images for hero and dishes.  

---

## 🛠️ Technologies Used

- HTML5 for semantic structure and multiple pages.[web:1]  
- CSS3 (Flexbox, Grid, media queries, gradients, animations) for a responsive, colorful UI.[web:3][web:36]  
- Vanilla JavaScript for interactive navigation and client‑side form validation.[web:54]  

---

## 🚀 How to Run

1. Download or clone the repository to your computer.[web:53]  
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.).  
3. Navigate between pages using the top navigation bar.

---

## 🌐 Deployment (GitHub Pages)

1. Push the project to a GitHub repository.  
2. In the repository, go to **Settings → Pages**.  
3. Set Source to `Deploy from a branch`, choose your main branch, and save.[web:17]  
4. After a few minutes, GitHub Pages will provide a public URL for your site.
